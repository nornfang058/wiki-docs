=== "Solution Code"

    	We strongly suggest that you try the exercise yourself and use the starter code before looking at the solution code.

	```html title="index.html" linenums="1"
	<!DOCTYPE html>
    <html>
        <head>
            <title>About Me</title>
        </head>
        <body>
            <h1>My Name</h1> 
            <p>I am in (grade level) grade.</p> 
            <p>I enjoy playing table tennis.</p>
        </body>
    </html>
	```

### Prompt (CodeHS)
Your task is to create a simple HTML page that introduces yourself. Follow the steps below to build your page:

1. Start with the Basic Structure:
* At the top of your document, declare the document type with <!DOCTYPE html>
* Create the <html>, <head>, and <body> tags to set up the structure of your HTML page.

2. Add a Title:
* Inside the <head> section, include a <title> tag with the text “About Me.” This title will appear in the browser tab.

3. Create a Heading for Your Name:
* Inside the <body> section, use an <h1> tag to display your full name.

4. Add Your Grade:
* Use a paragraph <p> tag to state your current grade level (e.g., “I am in the 10th grade.”).

5. Share an Activity or Hobby:
* Use another <p> tag to describe an activity or hobby you enjoy. You can write about why you like it or how you got interested in it.

6. Save and Preview:
* Save your HTML file and preview it in a web browser to make sure everything is displaying correctly.
