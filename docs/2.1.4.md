=== "Solution Code"
	!!! warning "Did you attempt the exercise before looking at the solution?"
    	We strongly suggest that you try the exercise yourself before looking up the solutions.

	```html title="index.html" linenums="1"
	<!DOCTYPE html> <!---->(1)
	<html>
		<head> <!---->(2)
			<title>Hello World</title>
		</head>

		<body> <!---->(3)
			<h1>Hello, Worldwide Web!</h1>
		</body>
	</html> <!---->(4)
	```

	1.	Your code should always start with `<!DOCTYPE html>` to tell the browser what version of HTML is being used.
	2.	The `<head>` section contains site information, and CSS in future exercises.
	3.	Everything inside the `<body>` tag is the main content of your webpage. As you move through CodedHS, more tags will be included, like `<nav>` and `<footer>`.
	4.	Make sure to end your HTML code with a closing `</html>` tag.
